# 🖥️ تطبيق سطح المكتب AdHub Pro (Windows Desktop)

تم تجهيز هذا المجلد لتمكين تشغيل نظام **AdHub Pro** كتطبيق ويندوز مستقل بصيغة **ملف تنفيذي واحد (`.exe`)** مع حماية تامة للشفرة، وميزة **النسخ الاحتياطي التلقائي الصامت لقاعدة بيانات Supabase والرفع الفوري إلى Google Drive**.

---

## 🌟 الميزات الرئيسية

1. **ملف تنفيذي واحد مستقل (Portable .exe):**
   - يعمل مباشرة بنقرة واحدة (Double Click) دون الحاجة لتثبيت أي برامج إضافية.
   - يتوفر أيضاً ملف تثبيت قياسي (Setup Installer).
2. **حماية شفرة المصدر (Source Code Protection):**
   - يتم تجميع وترجمة وتشفير ملفات المشروع داخل أرشيف ثنائي مغلق (`ASAR`) مدمج داخل الـ `.exe`، مما يمنع استخراج الأكواد أو التعديل عليها.
3. **النسخ الاحتياطي التلقائي عند كل تشغيل (Auto Backup & Upload):**
   - فور فتح البرنامج، يتم تنفيذ أمر `pg_dump` الصامت في الخلفية.
   - يتم حفظ نسخة محلية باسم: `FARES-BILB_YYYY-MM-DD_HH-mm-ss.dump` في مجلد `Documents/AdHub_Backups`.
   - يتم رفع الملف تلقائياً إلى مجلد `database-backups` على **Google Drive** المربوط في النظام عبر Google Apps Script.
   - يظهر إشعار Toast لطيف داخل البرنامج بنجاح العملية دون ظهور شاشات سوداء (CMD).
4. **أمان كلمات المرور:**
   - كلمة مرور قاعدة البيانات مشفرة ومدمجة في بيئة التشغيل المعزولة ولا تظهر في أي ملفات `.bat` مكشوفة.

---

## 🚀 كيفية بناء ملف الـ EXE

لبناء ملف الـ `.exe` في أي وقت، افتح Terminal في مجلد المشروع الرئيسي وشغّل الأمر التالي:

```bash
npm run desktop:build
```

### أين تجد الملف الناتج بعد البناء؟
ستجد الملفات التنفيذية جاهزة في المجلد:
`desktop/release/`

الملفات المتوفرة:
* **`AdHub-Pro-Portable.exe`**: البرنامج المحمول بملف واحد يعمل مباشرة.
* **`AdHub-Pro-Setup-0.0.0.exe`**: معالج التثبيت لويندوز.

---

## 🛠️ هيكلية مجلد desktop

```
desktop/
├── backupService.cjs   # محرك النسخ الاحتياطي الصامت والرفع إلى Google Drive
├── main.cjs            # العملية الرئيسية لتطبيق الويندوز (Electron Main)
├── preload.cjs         # جسر الأمان والتواصل بين الواجهة والنظام (IPC Bridge)
├── builder-config.json # إعدادات بناء وتشفير ملف الـ .exe (Electron Builder)
├── build.cjs           # سكربت البناء التلقائي المتكامل
└── release/            # المجلد الذي يحتوي على ملفات الـ EXE الناتجة
```
